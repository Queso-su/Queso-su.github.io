环境准备

1. 虚拟机配置

  • 虚拟化平台：Proxmox VE (PVE)
  • 虚拟机编号：110
  • 系统配置：
    • 操作系统：Ubuntu 24.04 LTS
    • 内存：≥16GB
    • 存储：≥50GB SSD
    • 网络：NAT或桥接模式

# 系统更新与基础工具安装
sudo apt update && sudo apt upgrade -y
sudo apt install git curl -y

Docker环境配置

1. 安装Docker & Docker Compose

# 如遇网络问题可改用清华源安装：
# 1. 设置清华Docker源
sudo apt-get install \
    ca-certificates \
    curl \
    gnupg
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://mirrors.tuna.tsinghua.edu.cn/docker-ce/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg
echo \
  "deb [arch="$(dpkg --print-architecture)" signed-by=/etc/apt/keyrings/docker.gpg] https://mirrors.tuna.tsinghua.edu.cn/docker-ce/linux/ubuntu \
  "$(. /etc/os-release && echo "$VERSION_CODENAME")" stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# 2. 安装Docker
sudo apt-get update && sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# 验证安装
docker --version && docker-compose --version

2. 配置镜像加速

sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<EOF
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn",
    "https://registry.cn-hangzhou.aliyuncs.com"
  ]
}
EOF
sudo systemctl restart docker

Dify部署

1. 克隆代码仓库

git clone https://github.com/langgenius/dify.git
cd dify/docker

2. 修改Docker Compose配置

# 复制示例文件
cp .env.example .env

# 编辑配置文件（按需修改端口/数据目录）
nano docker-compose.yml

建议修改项：

services:
  dify-web:
    ports:
      - "80:6060"  # 左侧为宿主机端口
    volumes:
      - ./data:/app/api/data

3. 启动服务

# 首次启动建议前台运行观察日志
docker-compose up

# 正常启动后使用后台模式
docker-compose up -d

# 查看实时日志（Ctrl+C退出）
docker-compose logs -f --tail=100

编辑 .env 文件添加：

DEEPSEEK_MODEL_1=deepseek-chat
DEEPSEEK_MODEL_2=deepseek-r1

聊天机器人部署

1. 创建测试机器人

  1. 在Dify控制台点击「创建应用」
  2. 填写应用信息：
    • 名称：test
    • 类型：对话型应用
    • 模型选择：DeepSeek-chat/r1

2. 模型切换配置

在应用设置的「模型配置」页：

model_config:
  provider: deepseek
  models:
    - deepseek-chat
    - deepseek-r1
  parameters:
    temperature: 0.7
    max_tokens: 2000

本地知识库部署说明

1. 扩展方案

当内存≥32GB时，可通过Docker扩展部署：

# 部署知识库服务
docker run -d --name ragflow \
  -p 8000:8000 \
  -v /opt/ragflow_data:/data \
  --memory=16g \
  registry.cn-beijing.aliyuncs.com/ragflow/ragflow:latest

# 连接Dify服务
在.env文件中添加：
KNOWLEDGE_BASE_ENDPOINT=http://ragflow:8000
